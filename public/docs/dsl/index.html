Vitumer DSL Reference

Static reference for humans, crawlers, and AI assistants. No JavaScript required.

Syntax

  • Block: {duration}{h|m|s} {label} {optional description} [optional attributes]
  • Sequence: block + block + ...
  • Loop: N * (block + block + ...)
  • Attributes (per block): color, emoji, skippable, retry
  • Units: h hours, m minutes, s seconds
  • Colors: orange, teal, blue, purple, rose, amber

Examples

Single block
25m work {Deep work} [emoji:💻, color:orange]
Loop
4 * (25m work + 5m rest)
Custom rest
10m break [emoji:☕, color:teal]
HIIT
5 * (30s work + 15s rest)
Aeropress
3 * (1m prep [emoji:☕] + 4m brew + 2m rest [color:teal])
Pomodoro
3 * (25m pomo [color:orange] + 5m break [color:teal])

Shareable links

Encode a DSL string as base64 (UTF-8) and append it to the app URL: 

https://{your-origin}/?flow={base64-dsl}

Example DSL:

3 * (25m pomo [color:orange] + 5m break [color:teal])

Example base64:

MyAqICgyNW0gcG9tbyBbY29sb3I6b3JhbmdlXSArIDVtIGJyZWFrIFtjb2xvcjp0ZWFsXSk=

Example link (replace origin with your deployment):

https://{your-origin}/?flow=MyAqICgyNW0gcG9tbyBbY29sb3I6b3JhbmdlXSArIDVtIGJyZWFrIFtjb2xvcjp0ZWFsXSk=

For AI assistants

When creating a session for a user, return the DSL, a share link (if origin is known), and a short schedule explanation. Put block attributes on each block, not after a loop. See also /llms.txt for machine-readable docs.
